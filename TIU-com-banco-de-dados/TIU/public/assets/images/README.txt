Imagens locais do TIU

As imagens desta pasta são ilustrações vetoriais SVG criadas especificamente para a versão demonstrativa do projeto.
Elas são usadas nos cards de profissionais e produtos para evitar dependência de imagens externas e permitir que o projeto funcione offline.

Os anúncios criados pelos usuários continuam podendo receber fotos próprias, que são armazenadas localmente no navegador via localStorage.
